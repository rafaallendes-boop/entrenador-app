Politica de Privacidad

Ultima actualizacion: 2026-07-08

Esta politica explica que datos tratamos, para que los usamos y como puedes gestionar o eliminar tu informacion.

Responsable y contacto

RallyIQ opera actualmente como producto en piloto. Para consultas de privacidad, soporte o solicitudes sobre tus datos, puedes escribir a hola@rallyiq.cl.

Datos que tratamos

  • Cuenta: nombre y correo asociados a tu inicio de sesion.
  • Entrenamiento: sesiones, planes, objetivos, disponibilidad, notas, RPE y registros diarios.
  • Salud y rendimiento declarados: sensaciones, sueno, energia, molestias, peso corporal y datos deportivos que ingresas manualmente.
  • Wearables opcionales: si conectas Whoop, usamos recovery, HRV, frecuencia cardiaca en reposo, strain y datos de sueno.
  • Datos tecnicos: informacion minima necesaria para operar, autenticar, sincronizar y diagnosticar errores del servicio.

Uso de datos de Whoop

La conexion con Whoop es opcional y requiere tu autorizacion. Usamos esos datos para mostrar readiness, prellenar campos editables del check-in diario y entregar contexto pasivo al coach de IA.

Los datos de Whoop no se usan para diagnosticar, tratar o prevenir enfermedades o lesiones. RallyIQ no reemplaza a un profesional medico, entrenador calificado u otro especialista de salud.

Para que usamos tus datos

  • Generar, registrar y ajustar planes de entrenamiento.
  • Sincronizar tus datos entre dispositivos.
  • Mostrar resumenes de carga, adherencia, readiness y progreso.
  • Dar contexto al coach de IA y a las recomendaciones dentro de la app.
  • Prestar soporte, mejorar el producto y mantener la seguridad del servicio.

No vendemos tus datos personales.

Almacenamiento y proveedores

La app funciona local-first: parte de tus datos se guarda en tu navegador. Si inicias sesion, tambien se sincronizan en infraestructura cloud para que puedas recuperarlos y usarlos entre dispositivos.

Usamos proveedores como Supabase para base de datos y autenticacion, Netlify para hosting y proveedores de IA para generar contenido dentro de la app. Estos proveedores solo reciben la informacion necesaria para prestar el servicio.

Los tokens de Whoop se almacenan cifrados del lado servidor. Los datos biometricos crudos no se exponen directamente al cliente; la app usa un resumen diario asociado a tu cuenta/atleta activo.

Tus controles

  • Puedes exportar tus datos desde Ajustes.
  • Puedes eliminar datos locales y remotos desde Ajustes.
  • Puedes desconectar Whoop desde Ajustes; al hacerlo se borran los datos Whoop asociados.
  • Puedes escribir a hola@rallyiq.cl para solicitar acceso, rectificacion o eliminacion.

Conservacion y seguridad

Conservamos tus datos mientras tu cuenta este activa o mientras sean necesarios para prestar el servicio. Aplicamos medidas razonables de seguridad, incluyendo autenticacion, conexiones cifradas y cifrado de credenciales de integraciones sensibles.

Cambios a esta politica

Podemos actualizar esta politica para reflejar cambios del producto, legales o de seguridad. La fecha de actualizacion indicara la version vigente.

Nota: RallyIQ esta en fase piloto. Esta politica busca explicar el uso real de datos dentro del producto y puede actualizarse antes de una version comercial amplia.
